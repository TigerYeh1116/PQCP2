## 中斷紀錄的保守復原

舊 250,000,000 次原抽樣長測停止於最後報告的 114,016,256 次，
沒有完整新解；報告仍是不完整，未訪問部分不計入排除。
850 點區域的舊報告只完成 442 點，gzip 串流缺少結尾，
不能直接通過原有完整紀錄審核。

`experiments/recover_coarse_ledgers.py` 僅在新目錄製作完整 JSON 行的副本，
不改寫原檔、不推測未完成行、不匯入符號模型／範數快取。
缺少原始 gzip footer 的事實保留在 `recovery_receipt.json`；
復原副本本身明確不是 UNSAT 證書。
損壞 deflate、已有但不符的 CRC、錯誤 JSON 與多 gzip member 均拒絕。

復原後仍由原審核工具逐筆核對全部目標、原始輸入順序及來源雜湊，
才取得 **442 個固定點、37,128 個完整目標**的閉合證書。
額外的 277 個目標紀錄不因可以讀取就被計入完整固定點。
副本與證書位於 `results/L86_ten_million_closed_prefix_20261011/`。
復原單元測試 3 個通過，包括缺 footer、半個 JSON 行及 CRC 損壞。

新增 `run_coarse_successor_search.py --resume-closed` 參數，
在真正凍結的新執行中載入上述已審核固定點；範數／符號快取從空開始。
接續位置為 `results/L86_coarse_successor_radius0_20261011_142226/coverage`。
其餘固定點正在處理，未完成部分不當成已排除或新的完整解。
