# C 獨立驗證器

## 按執行鍵（建議）

1. 在 VS Code 開啟根目錄、與 `main.py` 同一層的 `verify_pqcp.py`。
2. 點右上角 **Run Python File／執行 Python 檔案**，使用可輸入文字的整合終端機。
3. 在終端機輸入長度，例如 `68`，按 Enter。

入口會自動編譯同層的 `verify_pqcp.c`，並驗證專案根目錄的 `68.txt`，
不受啟動時工作目錄影響。數學驗證仍全部由 C 執行；Python 只負責啟動。
不需要安裝 Python 套件、PyTorch 或 Z3。電腦須有 `cc` 編譯器；
若 macOS 缺少編譯器，入口會提示安裝 Command Line Tools，不會自行安裝。
每次啟動重新編譯；編譯失敗不會執行舊版，也不會破壞原執行檔。

## 直接使用 C

也可以在 PQCP2 根目錄的終端機編譯：

```sh
cc -O2 -std=c11 -Wall -Wextra -Werror verify_pqcp.c -o build/verify_pqcp
./build/verify_pqcp
```

輸入長度，例如 `68`，程式會唯讀檢查目前目錄的 `68.txt`。
也能直接執行 `./build/verify_pqcp 68`，或
`./build/verify_pqcp 68 /完整路徑/68.txt`。
VS Code 若使用 C 的執行按鈕，請以專案根目錄為工作目錄，並使用可輸入文字的整合終端機。
不需要 Python、PyTorch 或 Z3。

每筆須包含目前專案的五個欄位：

```text
L=44
nonzero shifts=2,42
nonzero PACS=-4
a=11011001010100000010001100011110000100110111
b=01101000110010000111101000100011010010010100
```

從完整 a/b 重新以整數計算全部 S(u)，不信任已儲存的相關值。
檢查 binary、長度、S(0)=2L、恰好兩個非零 sidelobes、其絕對值為 4，
以及 S(u)=S(L-u)。u 與 L-u 分別計數。另核對檔案的 L、位移和 PACS。
序列正確但欄位錯誤也會列為不通過，並顯示原因。
不檢查不同紀錄是否等價，不移除、不改寫任何資料。

逐筆列出錯誤，最後列出總數、通過及不通過數。以 `L=` 作為紀錄開頭；
缺欄、重複欄位、未知文字及截斷紀錄不會靜默略過。
支援 CRLF、空白行及最後一行沒有換行字元。
空檔不算驗證通過。請在搜尋停止或使用檔案快照後驗證，避免同時追加資料。

退出碼：0 全部通過；1 有不通過紀錄或空檔；2 輸入、檔案讀取或資源錯誤。
L 上限 4096 是避免誤輸入導致大量運算的資源保護，不是 PQCP 的數學限制。
