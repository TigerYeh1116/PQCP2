# 相同奇數列的整數核：L86 受限構造的精確推導

這是本專案自行推導、已實作的有限族存在性檢查。未找到完整 L86 新解，
沒有證明一般 L86 PQCP 不存在，也不是新解發現速度提升 20% 的證據。
本文的 c、g 是「兩列偶數索引子序列」的平均與差，
與主搜尋的 antipodal C/G 編碼不同，不能直接互換。

## 1. 奇數位移化為線性核

下標均模 43。取二元符號列 E_A、E_B、O，定義

\[
x_{2i}=E_A(i),\quad x_{2i+1}=O(i+22),\qquad
y_{2i}=E_B(i),\quad y_{2i+1}=-O(i+22).
\]

令 c=(E_A+E_B)/2、g=(E_A-E_B)/2。
每個座標恰有一個 c 或 g 非零，非零值為 ±1。
設定兩列 E 的和都是 9，則 Σc=9、Σg=0。
定義 K_O(g;u)=Σ_i g(i+u)O(i)。直接展開得

\[
T(2r)=2\{P_c(r)+P_g(r)+P_O(r)\},\qquad
T(2r+1)=2\{K_O(g;r-21)+K_O(g;-r-22)\}.
\]

後兩個 K 的下標互為負，因此所有奇數位移恰為零，等價於
K_O(g;u)+K_O(g;-u)=0 對每個 u 成立。
這是 g 的實線性方程，而非能量近似。

令

\[
g_t(i)=\frac{O(i-t)-O(i+t)}2,\qquad 1\le t\le21.
\]

則 K_O(g_t;u)=[P_O(u-t)-P_O(u+t)]/2，是反對稱向量。
若 O 的循環卷積可逆，核的維度就是反對稱子空間的維度 21。
g_t 的 Gram 矩陣為

\[
G_{ts}=\tfrac12\{P_O(t-s)-P_O(t+s)\}.
\]

## 2. 完美 O：只能出現一個基底方向

假設 ΣO=1，P_O(0)=43、P_O(u)=-1（u≠0）。
O 的循環 Gram 是 44I-J，特徵值為 1、44，故可逆。
上式給 G=22I，且 K_O(g_t;u)=22(δ_{u,t}-δ_{u,-t})。

任意整數核向量 g 可寫成 Σα_t g_t。
α_t=〈g,g_t〉/22，故 q_t=22α_t 是整數。
若基底矩陣 B 在模 2 與模 11 都有列秩 21，
22g=qB 分別約化後強制每個 q_t 都被 2 和 11 整除。
因此每個 α_t 都是整數。這避免了只搜尋整數係數卻遺漏分數係數整數向量的問題。
程式對完整 8 個 O 平移代表逐一核對這兩個秩、Gram 與全部 K。

g 為三值列，所以 ||g||²≤43；同時 ||g||²=22Σα_t²。
因此 g=0 或 ±g_t，沒有其他三值核向量。
g=0 時 E_A=E_B，因為任意長度 43 二元列的 PACF ≡43≡3（mod 4），
T(2r)=2P_E(r)+2P_O(r)≡4（mod 8）。正常偶數旁瓣應為零，故不可能。

選 g=g_t 時令 κ=min(2t,43-2t)。其 PACF 為
P_g(0)=22、P_g(±κ)=-11、其餘非零位移為零。
負號 L86 目標強制

\[
P_c(0)=21,\quad P_c(\pm\kappa)=10,\quad
P_c(u)=1\ (u\ne0,\pm\kappa),\quad \sum c=9.
\]

c 的支撐由 g 的零位置唯一決定，21 個活躍位置中恰有 6 個負號。
8×21=168 個固定支撐子問題均完整 UNSAT，無 UNKNOWN。
記錄：`results/L86_same_perfect_O_complete_20261007/report.json`。
這個較早記錄只有腳本 SHA；後續版本才包含完整來源快照。

## 3. 單點翻轉 O：先證明整數格完整性，再列舉方向

從任一上述完美 O，把一個 -1 翻為 +1，得到 O'。
ΣO'=3，P_O'(u)∈{-5,-1,3}（u≠0）。
全部 8×21=168 個原料透過 O'(qi+r)、q∈Z_43^×、r∈Z_43，
得到 4 個代表。報告為每個原料保存 q、r 及代表的精確映射。
此處允許共同 decimation 及整列平移，E_A/E_B 仍任意；不是強制 E 列具有對稱性。
每個代表仍保留 κ=1..21 的全部例外位移。

在非零 Fourier 頻率，完美 O 的模為 √44，單點翻轉的擾動模為 2，
故 |F_O'|≥√44-2>0；零頻率為 3，循環卷積仍可逆。
G 的對角值在 20..24，非對角絕對值不超過 4，程式逐项核對。

使用整數 Smith 分解生成 43×21 整數矩陣 R，並用 Python 整數獨立核對

\[
B R=I_{21}.
\]

因此，若 g=αB 為整數列，α=gR 也是整數列。
R 隨報告完整保存；這個結論不需要讀者信任 Smith 分解的回傳狀態。
若不能生成或核對此證書，程式中止，不能排除其他整數向量。

設 a 是在位置 ±t 取 ±α_t/2 的反對稱向量，則 g 是 O' 與 a 的循環卷積，
||a||²=Σα_t²/2。Parseval 及前述下界給

\[
\|g\|^2\ge(24-2\sqrt{44})\sum_t\alpha_t^2
>10\sum_t\alpha_t^2.
\]

由 c 與 g 支撐互補且 Σc=9，c 至少有 9 個活躍位置，故 ||g||²≤34。
所以整數係數 Σα_t²≤3，非零係數只能是 ±1，最多三個。
三個方向的 norm 至少為 3×20-6×4=36，超出 34，故最多兩個方向。
程式逐一檢查 420 個雙方向組合（將第一個係數規範成正號）；
在這 4 個代表中，沒有組合能同時滿足 norm≤34 與逐座標三值限制。
這是這批原料的精確有限檢查，不是所有 O' 的普遍性質。

g=0 同樣由 mod-8 正常偶數旁瓣矛盾排除。
±g 的對稱商由交換 x/y 再同時交替換號實現，保留偶数位移目標。
剩下每個代表 21 個單方向。對每個 κ，令 w=43-||g||²，要求

\[
P_c(0)=w,\qquad P_c(u)=-P_g(u)-P_{O'}(u)
+2\mathbf1_{u\in\{\kappa,-\kappa\}}\ (u\ne0),\quad \sum c=9.
\]

c 有 (w-9)/2 個負號，且支撐固定為 g 的零位置。
4×21×21=1,764 個子問題全部完整 UNSAT，無 UNKNOWN。
含整數右逆及完整來源快照的重播記錄：
`results/L86_same_near_perfect_O_integer_certified_20261007/report.json`。
每個 SAT 的預定處理均要求原始 86 點 verifier 與完整固定目標吻合才保存。

## 4. 如何使用這個結果

不能把「相同 O」限制套在一般搜尋上：不同 O_A/O_B 不受本核分類約束。
目前只能避免在這兩個已決定的構造族反覆投入資源。
要探索不同奇數列，需要重新建立兩列交叉相關線性系統與整數格，
不能沿用 G=22I 或單點翻轉 norm 界。

實作：`solver/perfect_odd_kernel.py`、`solver/near_perfect_odd_kernel.py`。
專項測試含所有原料的等價映射、全部基底的奇數旁瓣消除、
偶數位移重建恆等式、整數右逆以及長度 3 核的完整三值空間核對。

Smith 分解的 API 依據 [SymPy 1.14 文件](https://docs.sympy.org/latest/modules/matrices/normalforms.html)；
以上 PQCP 核分類、norm 界及構造限制是本專案的推導。
